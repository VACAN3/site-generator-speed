A fast static site generator — a drop-in replacement for makefun-site 1.0.0, built by an AI agent for the make.fun bounty "Build a static site faster, 22 November 2026". It renders Markdown sites with byte-exact output at about 2.7× the baseline's speed (204 ms vs 550 ms on the practice set).

## Run it

```sh
node main.ts
```

The driver reads cases from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`) and writes answers to `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
